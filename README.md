# Чат-бот Алиса

Учебный чат-бот с веб-интерфейсом Gradio. Приложение принимает сообщения, позволяет выбрать язык ответа и отправляет текущий запрос вместе с историей диалога модели через TokenHarbor API.

## Запуск локально

Нужен Python 3.10 или новее.

1. Установите зависимости из корня проекта:

   ```bash
   python -m pip install -r requirements.txt
   ```

2. Задайте API-ключ TokenHarbor в переменной окружения `TOKENHARBOR_API_KEY`.

   macOS / Linux:

   ```bash
   export TOKENHARBOR_API_KEY="ваш_ключ"
   ```

   Windows PowerShell:

   ```powershell
   $env:TOKENHARBOR_API_KEY = "ваш_ключ"
   ```

3. Запустите приложение:

   ```bash
   python src/main.py
   ```

4. Откройте `http://127.0.0.1:7860`. Остановка — `Ctrl+C` в терминале.

Не сохраняйте секрет в коде, Docker-образе или Git. При смене ключа обновите файл `.env` и пересоздайте контейнер.

## Развёртывание на сервере через Docker Compose

На сервере должны быть установлены Docker Engine и Docker Compose plugin. Скопируйте на сервер файлы проекта, включая `Dockerfile`, `compose.yaml` и каталог `src`.

1. В корне проекта создайте файл настроек:

   ```bash
   cp .env.example .env
   nano .env
   ```

   Запишите в него действующий ключ TokenHarbor:

   ```dotenv
   TOKENHARBOR_API_KEY=ваш_новый_ключ
   ```

2. Соберите образ и запустите контейнер:

   ```bash
   docker compose up -d --build
   ```

3. Посмотрите журнал запуска при необходимости:

   ```bash
   docker compose logs -f
   ```

4. Когда входящий TCP-порт 7860 разрешён в сетевом экране сервера и у провайдера, откройте:

   `http://186.246.48.62:7860`

Остановить контейнер можно командой `docker compose down`. При постоянной публикации рекомендуется настроить HTTPS и домен через обратный прокси. В базовой конфигурации нет авторизации, поэтому доступ к опубликованному адресу открыт всем, кому он известен.

## Как устроен код

- `src/main.py` — точка входа; читает адрес и порт из `GRADIO_SERVER_NAME` и `GRADIO_SERVER_PORT`.
- `src/interface.py` — создаёт интерфейс Gradio с чатом и выбором языка.
- `src/chat_service.py` — читает `TOKENHARBOR_API_KEY`, формирует сообщения с учётом истории и вызывает TokenHarbor API.
- `Dockerfile` — описывает образ приложения.
- `compose.yaml` — задаёт запуск контейнера и публикацию порта 7860.

Схема работы: **пользователь → Gradio (`interface.py`) → обработчик (`chat_service.py`) → TokenHarbor → ответ пользователю**.

## Параметры

| Переменная | Назначение | Значение по умолчанию |
| --- | --- | --- |
| `TOKENHARBOR_API_KEY` | Ключ доступа к TokenHarbor; обязателен | Нет |
| `GRADIO_SERVER_NAME` | Адрес интерфейса внутри процесса | `127.0.0.1` |
| `GRADIO_SERVER_PORT` | Порт интерфейса | `7860` |

В Compose переменная `GRADIO_SERVER_NAME` задана как `0.0.0.0`, чтобы интерфейс принимал соединения, направленные в контейнер. Наружу публикуется порт `7860`.
